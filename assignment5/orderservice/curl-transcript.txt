3. REQUIRED ASSIGNMENT 5 TRANSCRIPT CASES


The following cases are required by the assignment and should be captured
with curl -v when the complete local service flow is available:

A. Create order:
   POST /orders
   Expected success: 201 Created
   Expected header: Location: /orders/{orderId}

B. Idempotent retry:
   Repeat POST /orders using the same Idempotency-Key.
   Expected behavior: original result is returned without duplicate work.

C. Conditional GET:
   GET /orders/{orderId} with:
   If-None-Match: "<etag>"
   Expected success when the ETag matches: 304 Not Modified
   No response body.

D. Conditional write:
   PATCH /orders/{orderId} with:
   If-Match: "<stale-etag>"
   Expected response: 412 Precondition Failed.

E. Bad request:
   Send malformed/invalid JSON.
   Expected response: 400 Bad Request.

F. Missing resource:
   GET /orders/999999
   Expected response: 404 Not Found.

G. Missing authentication:
   Protected endpoint without Authorization header.
   Expected response: 401 Unauthorized.
